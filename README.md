## 1\. Project Overview

This repository contains my individual practical database portfolio for
MIT 8103 -- Advanced Database Systems.

The project is based on a simulated University Library Management System
designed to demonstrate the application of advanced database concepts in
a university library environment.

The system focuses on managing library resources, borrowers, borrowing
activities, book returns and related records. Fictional records are used
for demonstration and practical database exercises.

The portfolio covers database design and modelling, query processing and
optimisation, transactions and concurrency, NoSQL and advanced data
models, and distributed and cloud database concepts.

## 2\. Case Study Description

The selected case study is the University Library Management System. It
represents a university library that manages books and other library
resources, registered borrowers, borrowing activities and returns.

**Nature of the system:**  
A library resource and borrowing management system.

**Database users:**

* Library staff and administrators.
* Students and other registered borrowers.

**Major data managed:**

* Books and library resources.
* Borrower records.
* Loan and borrowing records.
* Book return records.
* Fines.
* Library staff records.

**Key database operations:**

* Borrowing books.
* Returning borrowed books.
* Searching the library catalogue.
* Recording borrowing activities.
* Managing loan records.
* Calculating applicable fines.

The same case study is used throughout the five portfolio activities to
demonstrate how different database concepts can support the operations
of the library system.

## 3\. Portfolio Activities

This repository is organised into five portfolio folders, corresponding
to the practical activities required for the assessment.

### Portfolio 1: Database Design and Modelling

This activity focuses on the design and structure of the University
Library Management System. It covers the identification of database
entities and relationships, entity relationship modelling, relational
schema design, keys, constraints and normalisation.

**Folder:** [portfolio-1-database-design](portfolio-1-database-design/)

### Portfolio 2: Query Processing and Optimisation

This activity examines database query processing and optimisation. It
focuses on SQL queries, query execution and the application of
optimisation techniques to improve database query performance.

**Folder:** [portfolio-2-query-optimisation](portfolio-2-query-optimisation/)

### Portfolio 3: Transactions and Concurrency

This activity explores transaction management and concurrency in
database systems. It covers transaction control, commit and rollback
operations, isolation and the management of potential concurrency
issues.

**Folder:** [portfolio-3-transactions-concurrency](portfolio-3-transactions-concurrency/)

### Portfolio 4: NoSQL and Advanced Data Models

This activity examines NoSQL databases and advanced data modelling
approaches in the context of the University Library Management System.
It considers how alternative data models can support the storage and
management of library-related information.

**Folder:** [portfolio-4-nosql](portfolio-4-nosql/)

### Portfolio 5: Distributed and Cloud Database Exercise

This activity explores distributed and cloud database concepts as they
relate to the library system. It considers concepts such as replication,
sharding, availability, consistency and scalability.

**Folder:** [portfolio-5-distributed-cloud](portfolio-5-distributed-cloud/)
